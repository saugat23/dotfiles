# DWM Config

### To apply this config, first install dwm from suckless.org, build it and clone this repo on top of it.

### Copy the autostart.sh to your $HOME/.dwm/

### Make sure to install proper fonts and Display manager as per your needs & change the autostart.sh font and wallpaper config as per your needs or, if you are not using a display manager just make sure to add   `exec dwm` in your ~/.xinitrc

### This config is built on top of this config `https://github.com/octagony/dwm-config-files`   So, make sure to visit that for extra configurations.
